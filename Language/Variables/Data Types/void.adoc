= void

// OVERVIEW SECTION STARTS
[#overview]
--

[float]
=== Опис
Ключове слово `void` використовується тільки в оголошеннях функцій. Воно вказує на те, що функція не повинна повертати жодної інформації, з якої вона була викликана.
[%hardbreaks]

--

Код показує, як використовувати `void`.

[source,arduino]
----
// Ця функція не повертає жодної інформації
void setup() {
  // ...
}

// Ця функція не повертає жодної інформації
void loop() {
  // ...
}
