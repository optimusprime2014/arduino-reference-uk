= String()

// OVERVIEW SECTION STARTS
[#overview]
--

[float]
=== Опис
Конструює екземпляр класу String. Існує кілька версій, які створюють рядки з різних типів даних (тобто форматують їх як послідовності символів), зокрема:

* стала послідовність символів, у подвійних лапках (тобто масив char)
* одиночний сталий символ, у одинарних лапках
* ще один екземпляр класу String
* стале ціле число (int або long)
* стале ціле число (int або long), використовуючи вказану систему числення
* змінна цілого числа (int або long)
* змінна цілого числа (int або long), використовуючи вказану систему числення
* число з плаваючою крапкою (float або double), використовуючи вказану кількість десяткових знаків

Створення рядка з числа призводить до появи рядка, який містить ASCII-представлення цього числа.
Значенням за замовчуванням є десяткова система числення, тому
[source,arduino]
----
String thisString = String(13);
----
дає вам рядок "13". Однак ви можете використовувати й інші системи. Наприклад,


[source,arduino]
----
String thisString = String(13, HEX);
----

дає вам рядок "d", який є шістнадцятковим представленням десяткового значення 13. Або, якщо ви віддаєте перевагу двійковій системі числення,

[source,arduino]
----
String thisString = String(13, BIN);
----

дає вам рядок "1101", який є двійковим представленням числа 13.
[%hardbreaks]


[float]
=== Syntax
`String(val)` +
`String(val, base)` +
`String(val, decimalPlaces)`


[float]
=== Parameters
`val`: змінна для форматування як String. Допустимі типи даних: string, char, byte, int, long, unsigned int, unsigned long, float, double. +
`base`: (опцірнально) система числення, у якій слід форматувати ціле значення. +
`decimalPlaces`: *тільки якщо val має тип float або double*. Бажана кількість десяткових знаків.


[float]
=== Результат
Екземпляр класу String.

[float]
=== Приклад коду
Усі наведені нижче оголошення є дійсними для Strings.
[source,arduino]
----
String stringOne = "Hello String";
String stringOne = String('a');
String stringTwo = String("This is a string");
String stringOne = String(stringTwo + " with more");
String stringOne = String(13);
String stringOne = String(analogRead(0), DEC);
String stringOne = String(45, HEX);
String stringOne = String(255, BIN);
String stringOne = String(millis(), DEC);
String stringOne = String(5.698, 3);
----
